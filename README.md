# Kỹ thuật Audio-Video — IUH

Kho tài liệu học tập môn **Kỹ thuật Audio-Video** tại IUH.

## Nội dung

| Thư mục | Nội dung |
|---|---|
| `00_Chuong_trinh_mon_hoc/` | Đề cương/chương trình môn học |
| `01_Bai_giang/` | Bài giảng tổng hợp và bài giảng theo chương |
| `02_Tai_lieu_tieng_Anh/` | Tài liệu tiếng Anh theo chương |
| `03_File_goc/` | File nén và tài liệu gốc |
| `Bai giang/` | Bộ bài giảng bổ sung |

Repository hiện có tài liệu chương trình môn học, các bộ bài giảng tổng hợp, bài giảng chương 1–6, tài liệu tiếng Anh C1–C14 và các file gốc/nén. 

## Nội dung tài liệu

Các tài liệu tập trung vào Kỹ thuật Audio-Video, bao gồm nội dung bài giảng về truyền hình analog/digital và các chương học được lưu dưới dạng PDF, cùng tài liệu tiếng Anh theo chương.

## Mục đích

- Hệ thống hóa tài liệu môn Kỹ thuật Audio-Video.
- Dễ tra cứu bài giảng theo chương.
- Lưu riêng tài liệu tiếng Anh và file gốc.
- Hỗ trợ học tập và ôn tập.

## Lưu ý

Một số tài liệu có thể thuộc bản quyền của giảng viên, tác giả hoặc nhà xuất bản. Vui lòng sử dụng cho mục đích học tập và tôn trọng quyền sở hữu trí tuệ.
